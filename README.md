# Park Siwoo Fan Archive

박시우의 매거진, 사진, 활동 기록, IG 라이브를 하나로 모은 정적 GitHub Pages 사이트입니다.

## 폴더 구조

```text
park-siwoo/
├── index.html          # 통합 메인 페이지
├── assets/             # 메인 공통 스타일과 스크립트
├── magazine/           # 기존 siwoo 저장소
├── archive/            # 기존 siwoopic_archive 저장소
├── live/               # 기존 siwoo_live260907 저장소
└── schedule/           # 기존 siwoo_sche 저장소
```

각 하위 사이트의 기존 HTML과 이미지·오디오 경로는 유지했습니다. 모든 하위 페이지 오른쪽 아래의 `SIWOO HOME` 버튼으로 메인 페이지에 돌아올 수 있습니다.

## GitHub에 올리기

이 사이트에는 약 52MB의 음성 파일이 포함되어 있어 GitHub 웹사이트의 `Upload files` 기능만으로는 전체 업로드가 어렵습니다. **GitHub Desktop**으로 올리는 방법을 권장합니다.

1. GitHub Desktop에서 `userman123411/park-siwoo` 저장소를 Clone합니다.
2. 이 폴더 안의 파일과 폴더를 Clone된 `park-siwoo` 폴더 안으로 복사합니다.
3. GitHub Desktop에서 변경 내용을 확인하고 `Commit to main`을 누릅니다.
4. `Push origin`을 누릅니다.

## GitHub Pages 켜기

1. GitHub에서 `park-siwoo` 저장소를 엽니다.
2. `Settings` → `Pages`로 이동합니다.
3. `Build and deployment`의 Source를 `Deploy from a branch`로 설정합니다.
4. Branch는 `main`, 폴더는 `/(root)`를 선택하고 `Save`를 누릅니다.
5. 배포가 끝나면 아래 주소에서 사이트를 볼 수 있습니다.

```text
https://userman123411.github.io/park-siwoo/
```

## 기존 저장소와의 관계

기존 네 저장소는 삭제하지 않아도 됩니다. 이 통합 저장소에는 현재 시점의 파일을 복사해 두었으며, 이후 새 자료가 생기면 해당 하위 폴더만 업데이트하면 됩니다.
